# 季候图谱 · 视觉精修验收

设计约束：保留米白纸张、鼠尾草绿、朱砂点色、衬线标题与三维季候花冠。Awwwards、Webby Awards、FWA 作为质量目标；不宣称获得这些奖项或没有任何审美改进空间。

| 维度 | 本轮调整与检查 |
| --- | --- |
| 排版 | 放大正文、数据说明、筛选标签及图表旁注，保持衬线标题与等宽数字的分工。 |
| 留白 | 统一章节、指标、图表和筛选区间距，保留刊物式分隔线与开放布局。 |
| 层级 | 保留标题和季候雕塑为主视觉；加强当前导航、核心数值及选中形态的标识。 |
| 色彩 | 保留原配色，提高次级文字对纸色背景的可读性，继续用文字与下划线表达状态。 |
| 动效 | 控件采用短时颜色变化，继续保留现有图谱过渡，减少动态效果模式关闭装饰过渡。 |
| 微交互 | 增大按钮、年份及筛选触控范围，补充悬停和按下反馈、键盘跳至内容入口。 |
| 响应式 | 1440、768、390 像素检查四个页面，无页面横向溢出；手机地区三维图采用较远初始视角，重置视角采用相同规则。 |
| 原创性 | 保留季候花冠、年度山脊、观测星轨与观测手记的项目专属表达。 |

验证采用本机 Chrome。应用内浏览器连接组件缺失，未完成应用内浏览器复验。检查包含导航、年度与地区筛选、筛选重置、三种图谱形态、平面图谱、沉浸模式、快捷探索、键盘入口和减少动态效果。现有 Python 与 JavaScript 测试通过。

本次提交只包含视觉精修、键盘入口与地区矩阵的窄屏视角；未同步其他工作目录中尚未提交的数据、后端和病原学功能改动。
