# 流感观测站：季候图谱与趋势分析平台

基于 Flask、MySQL、jQuery、ECharts 5 和本地 ECharts GL 2.0.9 的可运行参赛原型。平台串联数据导入、质量检查、多维分析、历史留出验证及报告导出，以“流感季候图谱”为视觉主题。

界面采用编辑式科学图谱设计：暖骨白纸面（`#f3f0e7`）、森林墨正文（`#253d36`），搭配灰绿与少量朱砂。顶部导航串联四个章节，宋体标题、细分隔线、图号、留白与来源注记构成观测手记的阅读节奏。首屏以原生 WebGL 2 三维数据雕塑呈现月份与跨年变化，并保留可切换、可降级的原生 SVG 年度季候图谱，再展开读数、趋势和地区分析。纸面纹理由本地 CSS 内嵌 SVG 生成，图谱与图标均由代码绘制；没有引入外部生物插图、联网素材或远程字体。

**当前默认数据是 SQL 初始化的教学模拟数据：2021—2025 年，共 60 条月度记录。项目没有接入实时疫情，也未宣称获得国家级奖项；当前规模不构成海量大数据处理能力。** 用户可以导入自行收集的月度数据，但来源说明是用户自述，平台不自动核实其真实性。

## 四个功能页面

| 页面 | 功能 |
| --- | --- |
| 季候图谱 | 三种原生 WebGL 2 数据雕塑及平面 SVG 图谱；月切片、后台统计、图像导出；年度 ILI、实验室阳性率、年度病例、月度峰值；月度同比、自动观察文字、可旋转地区年度矩阵、地区对比 |
| 时间与人群 | 跨年季节热力图、点击年月联动年度、点击年龄组筛选、年度月均值与缺月完整度对照 |
| 趋势推演 | 比较季节朴素与季节漂移基线，展示最后 12 个月留出验证、MAE、历史截面和随后六个月外推 |
| 数据档案 | 来源档案、缺月及重复检查、CSV 两步导入、月度记录搜索与分页、原始 CSV 导出 |

顶部数据集、年度、地区、年龄筛选联动分析。预测使用所选数据集的完整历史与地区、年龄条件，**年度下拉框不会截断预测训练序列**。原始记录列表展示整个数据集，不应用地区或年龄系数。

## 运行

在 Windows PowerShell 中进入现有 D 盘目录。若还没有依赖，可安装 Flask 与 PyMySQL，并将下载缓存显式放到 D 盘：

```powershell
Set-Location D:\yang-zicheng\task6
python -m pip install flask pymysql --cache-dir D:\yang-zicheng\.cache\pip
```

默认教学数据需要本地 MySQL。首次准备时，在 MySQL 客户端执行 `sql/init_influenza.sql`；不必执行讲义专用的学生表脚本。原有四张流感表及其结构保持不变。

推荐在启动服务前设置连接环境变量，避免在文档或分享的源码中填写明文密码：

```powershell
$env:FLU_DB_HOST = '127.0.0.1'
$env:FLU_DB_PORT = '3306'
$env:FLU_DB_USER = 'root'
$env:FLU_DB_NAME = 'influenza_db'
$secureFluPassword = Read-Host '请输入本地 MySQL 密码' -AsSecureString
$env:FLU_DB_PASSWORD = [System.Net.NetworkCredential]::new('', $secureFluPassword).Password
python app.py
```

打开[本地平台](http://127.0.0.1:5000/)。程序仍以 `python app.py` 启动，本地开发服务监听 `127.0.0.1:5000`。ECharts、ECharts GL、jQuery、样式和图标均为本地资源，无 CDN；已安装运行依赖后，展示与分析不依赖联网。

MySQL 暂不可用时，默认数据请求返回明确错误，不用伪造数据替代。仍可进入“数据档案”导入 CSV，或选择已保存的独立数据集；导入集的读取和预测不依赖 MySQL。

## 数据与统计口径

| 指标 | 口径及筛选行为 |
| --- | --- |
| ILI% | 数据源提供的流感样病例比例；不是实验室阳性率，也不作为人群发病率解释。默认年度值来自 `flu_yearly.rate`，月度值来自 `flu_monthly.rate` |
| 地区、年龄 ILI | 全国指标 × 对应年度地区系数 × 年龄系数；是演示性估算，不是各地区、各年龄组独立采集的监测值 |
| 实验室阳性率 | `flu_yearly.pos_rate` 的全国、全部年龄年度汇总；不乘地区或年龄系数，不随这两个筛选变化 |
| 年度流感样病例 | `flu_yearly.cases` 的全国、全部年龄年度汇总，沿用原 SQL 的“万人次”单位；不随地区或年龄筛选变化 |
| 月度活动峰值 | 所选年度可用月度 ILI 的最大值及月份；与数据库的年度峰值周 `peak_week` 不同 |
| 年度对照中的月均 ILI | 可用月度值的算术平均；没有月度分母权重，不等同于按就诊量等分母重新计算的年度加权比例 |
| 5% 观察线 | 仅用于默认模拟数据的教学展示；不是医学预警阈值，导入集不显示此观察线 |

导入集只提供月度 ILI，因此仅有“全国 / 全部年龄”选项，不虚构地区与年龄系数；病例数、阳性率、样本数和峰值周均为未知并显示“—”。导入集年度卡片明确标注“月均 ILI 比例”。数据库年度汇总与月度算术平均也可能不同，平台分别保留两种口径。

缺测月份保留为 `null`，曲线断开、热力图留白、年度季候图谱不绘制花瓣；数值 `0` 是有效观测，在图谱零值内环上显示空心圆。默认数据档案中的时间来自初始化脚本修改时间，**不是疫情数据更新时间**；导入集记录的是保存时间，也不冒充监测发布日。

## 三维数据雕塑与观测体验

`static/js/specimen-gl.js` 直接使用浏览器原生 WebGL 2 绘制数据雕塑，不引入额外三维库、远程模型或联网依赖。同一条记录在不同形态间保持年月与 ILI% 的对应关系；图形是数据编码，不是流感病毒、抗原或人体结构的生物学模型。

| 形态 | 数据编码 |
| --- | --- |
| `corolla` · 季候花冠 | 月份对应绕环角度，花瓣长度对应月度 ILI%，颜色区分年份；跨年共用刻度，环形不是构成占比 |
| `strata` · 年度山脊 | 横向为月份，纵深为年份，高度为月度 ILI%；缺测处断开，不压缩月份，也不补零 |
| `orbit` · 观测星轨 | 节点沿真实年月顺序展开为螺旋，每个节点对应一条月度记录，高度为 ILI%；螺旋位置组织时间，不表示地理位置或生物轨迹 |

鼠标或单指拖拽可旋转，滚轮或双指可缩放；悬停显示年月与精确读数，点击花瓣或节点选择年月，年份图例联动年度。重置按钮恢复默认镜头。有效零值保留为零值标记，缺测记录不生成几何图形；高度或长度刻度在同一筛选条件的各年份间统一。地区、年龄条件仍使用既有系数估算，不产生新的独立观测。

形态切换采用 **800 毫秒**过渡，静止时按需绘制帧，不自动旋转。通过 `IntersectionObserver` 检查实际视口，场景滚出视口附近的预留区域时暂停绘制和月份播放；离开总览、切换平面图谱或浏览器标签页进入后台时也会暂停。系统启用“减少动态效果”（`prefers-reduced-motion: reduce`）时，跳过形态补间并禁用月份自动播放；运行中开启该设置也会立即停止播放与读数动画，并落到确切月份。WebGL 2 不可用或图形上下文出错时，保留可交互的平面 SVG 图谱及精确读数。

`static/js/experience.js` 组织观测交互：

- **月份切片**：拖动时间轴选择全年或单月；播放由用户点击启动，以 1.8 秒为间隔推进。播放切换采用先消失再浮现的节奏：旧图及月度读数先用 220 毫秒淡出，在不可见时换到下一月，停留 40 毫秒后用 640 毫秒淡入并轻移归位。滑块继续用 650 毫秒缓动，12 月到 1 月在两端衔接，不倒扫中间月份。拖动时滑块直接跟手，三维高亮以 180 毫秒跟随最新目标；暂停立即停止继续推进，当前淡出／浮现自然完成。读数始终是实际观测值，不插出中间 ILI 数字；原生滑块、无障碍标签、URL 和环境音联动仍使用整数月份。
- **年份切换**：年份图例和顶部年度下拉框共用过渡：旧图、中心年份、年度读数与统计先淡出 280 毫秒，在不可见时切换年度，再经 40 毫秒停留后用 720 毫秒浮现。连续点击只保留最新目标，并从当前透明度继续，避免旧请求排队或突然回闪；年份图例节点保持稳定，保留键盘焦点与高亮过渡。清空数据时丢弃待切换年度，离开总览或启用减少动效时立即稳定到最新选择。
- **沉浸查看**：放大观测场景，可用退出按钮或 Escape 返回；键盘焦点保持在放大场景的可操作项中。
- **保存图像**：三维模式导出当前视角的 PNG，附带形态名称、年度、地区与年龄范围、月份切片以及模拟数据或用户导入说明；平面模式导出 SVG。文件保存位置由浏览器决定，请选择 D 盘。图像导出与“导出观测手记”的打印报告相互独立。
- **快捷导航**：Ctrl+K（macOS 为 Command+K）打开搜索式导航，可跳转章节、形态或年份，并通过方向键与 Enter 操作。
- **URL 恢复**：地址参数保存数据集、年度、地区、年龄组、形态和月份切片，刷新或分享地址可恢复有效选项；地址不会上传本地数据集，接收方仍需访问同一服务及相应数据集。

## 可选季候环境音

“听见季候”使用浏览器 Web Audio API，在本地合成缓慢轮换的和弦、柔和弦音、滤波空气声与稀疏玻璃音符，不下载音频文件，不使用流媒体或外部音乐素材。声音**默认关闭**；只有用户点击开启按钮时才创建音频连接。切换月份、场景、筛选或调整音量都不会自行开启声音。

月份选择预设音符，场景形态改变音色的滤波设置；全年状态使用预设旋律。音乐只提供艺术氛围，**没有把 ILI%、病例数、阳性率或医学风险映射为声音，也不作为医学数据声化或预警**。无有效数据时不触发月度玻璃音符，已手动开启的环境和弦仍可保留。

音量独立于场景和月份播放控制，初始为 24%，支持拖动音量条及静音按钮；音量 0 为真正静音，取消静音恢复最近的非零音量。切换月份不重建音频连接；关闭声音时清除调度与音符，通过短渐出后暂停音频连接，避免突然切断。

离开“季候图谱”总览或浏览器标签页进入后台时，音乐渐出暂停；返回后仅尝试恢复此前由用户手动开启的状态。浏览器若阻止恢复，会保持关闭并提示再次点击。普通页面离开会释放音频资源；浏览器前进后退缓存（BFCache）则暂停后在返回时按原先的用户选择恢复。刷新页面仍默认关闭，不记忆自动播放。

`static/js/soundscape.js` 提供声音合成与生命周期管理，`static/js/sound-controls.js` 负责启用、静音、音量和状态提示，`experience.js` 传递月份、形态与页面活动状态。浏览器不支持 Web Audio 或设备不可用时保持静音并提示环境音不可用，图谱、读数和数据分析仍可使用。

## 浏览器后台统计

`static/js/signal-worker.js` 在本地 Web Worker 中分析时序，计算不阻塞场景交互，也不新增服务端请求。输入仍是当前数据集及地区、年龄条件下的月度 ILI%：默认数据为教学模拟数据，非全国或非全部年龄条件为系数估算。以下结果属于统计探索，**不是 AI 模型、医学预警、临床预测或 GPU 性能基准**。

| 结果 | 算法与解释 |
| --- | --- |
| 12 月滞后相关 `lag12` | 按真实年月对齐相隔 12 个月的有效观测，仅至少 12 对时计算 Pearson 相关系数；范围为 −1—1，不是准确率。缺月不压缩时间，常量序列相关性未定义时返回空值 |
| 稳健趋势 | Theil–Sen 成对斜率的中位数，单位为**百分点/月**；时间间隔使用真实月份。超过 360 个有效观测时等间隔取至多 360 点，并注明采样；不是未来外推模型 |
| 同月统计偏离 | 对所选年的每个月，仅用其他年份同月至少 3 个观测计算留一中位数与 MAD；当 `|robustZ| > 3.5` 时标记统计偏离。所选值不进入自身基线；样本不足或 MAD 为 0 时不判异常，没有医学预警含义 |
| 形态邻居 | 仅比较双方均有完整 12 月的年份：分别做 z 标准化后计算月度 RMSE，距离越小表示季节形态越近；常量序列标准化为零。至少需要两个完整年份，不是预测或传播关系 |
| 覆盖度 | 统计最早至最晚年度全部月份的应有数、有效观测数与缺测数；0 为有效观测，缺失年份与缺失月份均保留时间位置 |

后台统计不可用时，页面说明原因，图谱与精确读数仍可使用。新消息以标识区分结果，避免快速切换筛选时展示过期计算；重复年度先合并去重，同月冲突或越界数值返回明确错误。

## CSV 导入、存储与导出

CSV 第一行必须依次为 `year,month,rate`，仅这三列；支持 UTF-8（含 BOM）或 GB18030，单文件不超过 2 MB：

```csv
year,month,rate
2025,1,3.2
2025,2,4.1
2025,3,0
```

| 字段 | 校验 |
| --- | --- |
| `year` | 1900—2100 的四位整数 |
| `month` | 1—12 的整数 |
| `rate` | 0—100 的有限数字，单位为百分数；`3.2` 表示 3.2%，不要加 `%` |

重复年月、错误列数、越界值、空数值、`NaN` 和无穷值会拒绝整份文件；不会静默删掉错误记录后继续。空白行会忽略并写入质量提示。缺月数据可以保存用于展示，质量面板按覆盖年度检查缺月；是否能预测另按实际观测区间的连续性判断。

导入流程有两步：

1. 选择文件、填写数据集名称和来源，点击“检查并预览数据”。服务端校验全部记录，返回质量结果及前 12 条预览，同时保存一个临时预览；此时尚未新增正式数据集。
2. 核对后点击“确认保存数据集”，以预览 token 创建独立数据集并自动切换。预览有效期为一小时；更换文件或编辑名称、来源后需要重新预览。

所有新增数据保持在当前 D 盘工程内，默认根目录为 **`D:\yang-zicheng\task6\data`**（由 `app.config['DATA_DIR']` 配置）：

| 位置 | 内容 |
| --- | --- |
| `data/datasets/<id>.json` | 已确认的独立数据集、来源档案及质量结果 |
| `data/previews/<token>.json` | 尚待确认的预览，提交成功后移除对应预览 |
| `data/uploads/` | multipart 上传可能落盘时的临时目录；小文件可在内存中暂存 |

独立 JSON 数据集不覆盖原 MySQL，也不改变四张表。保存使用同目录临时文件再替换目标文件。过期预览会拒绝提交；当前没有后台定时清理机制。

“导出 CSV”下载当前搜索命中的全部**原始**月记录，而非仅当前分页或按系数估算的结果，列顺序仍为 `year,month,rate`。浏览器下载时请选择 D 盘保存位置。“导出观测手记”打开浏览器打印，包含来源、筛选、统计口径和月度读数；先访问“趋势推演”完成计算后，可附上当前条件的预测摘要。可在打印窗口保存 PDF，文件位置由浏览器选择。该功能没有新增服务端导出接口。

## 预测方法与限制

预测要求至少 **36 个月连续、无重复的月度记录**；实际首月到末月之间有缺月则不预测。首尾不是完整自然年，只要观测区间连续且不少于 36 月，仍可预测。

1. 将最后 12 个月作为留出集，其之前所有月份作为训练期。
2. 季节朴素基线用训练期去年同月值预测。季节漂移基线在此基础上加入训练期平均同比变化；验证预测只使用训练期信息。
3. 比较留出集 MAE（平均绝对误差，单位为**百分点**），选用误差较低的方法；相同时沿用季节朴素基线。
4. 用全部已知历史重新生成选定方法的随后六个月外推；预测输出限制在 0—100%。

**留出集同时用于选模，不是选模后额外保留的测试集。** 页面 MAE 不是准确率，也不能视为未参与选择的独立测试表现。模型没有计算置信区间，因此不绘制或捏造置信带。地区、年龄估算序列及系数变化也会影响预测，不代表分地区、分年龄的真实模型能力。

默认数据末月为 **2025-12**：训练期为 2021-01—2024-12，留出验证为 2025-01—2025-12，随后外推为 **2026-01—2026-06**。按当前 2026-10-21 日期，这些外推月份已经过去，属于历史截面演示，不能称为当前未来疫情预报。页面会根据本地日期提示历史演示窗口；并没有读取 2026 年实测记录来核验这段外推。

## 页面与接口

| 方法及路径 | 参数 / 请求 | 返回及行为 |
| --- | --- | --- |
| `GET /` | 无 | 平台模板；`#overview`、`#analysis`、`#forecast`、`#data` 为同页功能导航 |
| `GET /about` | 无 | 保留的 Flask 讲义补充页面 |
| `GET /api/datasets` | 无 | `{datasets: [...]}`，列出默认教学集与已导入数据档案；不需要查询 MySQL |
| `GET /api/influenza` | 可选 `dataset`，默认 `database`，或导入集 ID | 保留原接口；返回 `yearly`、`regionByYear`、`groups`，以及新增的 `meta`、`records`、`quality` |
| `POST /api/import/preview` | multipart：`file`（CSV）、`name`、`source` | 校验后返回 `token`、前 12 条 `preview`、`quality`、`meta`；尚未正式导入 |
| `POST /api/import/commit` | JSON：`{"token":"预览标识"}` | 保存独立数据集，返回 `datasetId` 和 `meta`；不写 MySQL |
| `GET /api/forecast` | 可选 `dataset`、`region`、`group`；默认教学集、全国、全部年龄 | 返回 `available`、`reason`、`method`、`trainingEnd`、`validation`、`history`、`validationPoints`、`forecast`、`note` |

前端继续通过 jQuery `$.getJSON('/api/influenza', ...)` 读取 Flask JSON。校验失败返回 400，找不到数据集或预览返回 404，MySQL 不可用返回 503；接口以 `error` 及可用的 `details` 说明原因。预测条件不足时正常返回 `available: false` 和原因，不伪造预测值。
